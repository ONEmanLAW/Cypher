# BeatPath

## Install

```sh
bun install
```

Puis selon ton OS :

**Windows**
```sh
bun run server:setup:win
```

**Mac / Linux**
```sh
bun run server:setup:mac
```

## Run

Dans deux terminaux séparés :

**Frontend**
```sh
bun run dev
```

**Backend**

Windows :
```sh
bun run server:win
```

Mac / Linux :
```sh
bun run server:mac
```
